ภาพรวม

คาบนี้อธิบาย ค่าเฉพาะ (eigenvalue) และ เวกเตอร์เฉพาะ (eigenvector) วิธีหาจากสมการลักษณะเฉพาะ และการนำไปใช้ทำ diagonalization ของเมทริกซ์

หัวข้อ

การหา eigenvalue

  • ตั้งสมการ det(A − λI) = 0 แล้วแก้หา λ
  • เมทริกซ์ n×n มี eigenvalue ได้ไม่เกิน n ค่า (นับซ้ำ)

Diagonalization

  • A = PDP⁻¹ เมื่อ P ประกอบด้วย eigenvector ที่อิสระเชิงเส้น

นิยาม

ค่าเฉพาะ (eigenvalue)
สเกลาร์ λ ที่ทำให้ Av = λv มีคำตอบ v ≠ 0
สมการลักษณะเฉพาะ (characteristic equation)
det(A − λI) = 0

อาจารย์เน้น

  • “ข้อนี้ออกสอบแน่นอน” — การพิสูจน์ว่า eigenvector ต่าง eigenvalue อิสระเชิงเส้น
